# Anti-Generic Checklist

Run this before presenting any design-system, page design or built section. If an item is present **and the brief didn't ask for it**, replace it with a choice made for this company — and say what you changed.

## The current "AI-generated" tells
1. Warm cream background (~#F4F1EA) + high-contrast serif display + terracotta/clay accent (~#D97757).
2. Near-black background with one acid-green or vermilion accent.
3. Broadsheet layout: hairline rules, zero radius, dense newspaper columns — applied regardless of subject.
4. The SaaS-card kit: everything chopped into identical rounded cards, one radius everywhere, the same soft grey shadow, gradient washes as decoration.
5. Template chrome: tracked-out ALL-CAPS eyebrow above every heading · meta strings joined with middle dots (A · B · C) · "WORD — fragment" labels · tinted near-black (#0B0B0B/#111) instead of a chosen dark · monospace for small labels · "→" appended to every link/button.
6. Accenting one word of a headline in italic/colour.
7. Big-number-with-small-label stat rows + gradient accent as the default hero.
8. Numbered markers (01/02/03) on content that isn't a sequence.
9. Fade-and-slide-up on every section; hover lift on every card.
10. Purple-to-blue gradients, glassmorphism and glow without a concept reason.
11. Emoji as icons; mixed icon styles; default icon set positioning (icon-left-of-heading in every card).
12. Inter/Roboto/Poppins/Montserrat chosen because they're safe, not because they fit.
13. Generic stock-photo hero with a dark overlay and centred text.
14. Copy like "Elevate your…", "Unlock the power of…", "Seamless", "Revolutionize", "Your journey starts here".

All of these are legitimate *when chosen* for a brief. They fail when they're defaults.

## The swap test
Replace the logo and name with a competitor's. If the page still works unchanged, it isn't designed for this company yet.

## The concept test
Point to where each object from the two-object concept shows up in: type, colour, layout, signature element, motion. If you can't point to it, the concept is decorative, not structural.

## The restraint test
Is there exactly one memorable thing per view? Remove one accessory before shipping.
