# Phase 2 — The Two-Object Creative Philosophy

The heart of the system. Two seemingly unrelated objects become the foundation of an original visual identity. Deliverable: `docs/full-dev/02-concept.md` (template: `templates/02-concept.md`). ★ Gate.

## 2.1 Select two objects
- **Object A — Identity object:** represents the company's purpose, business, values, industry or ambition.
- **Object B — Unexpected object:** from a completely different world, no obvious relationship. Industrial, scientific, biological, mechanical, architectural or ordinary everyday objects are all fair game — not just "beautiful" ones.

Examples (not restrictions): cybersecurity + spiderweb · architecture studio + seashell · fintech + mechanical clock · logistics + ant colony · AI + kaleidoscope · fashion + geological formation.

**Generate, then choose.** List 3 candidates for A and 8–10 for B across different worlds (nature, machines, tools, architecture, science, kitchen, sport, music, materials). Pick the 2–3 strongest pairs and run 2.2–2.4 quickly on each; present the best pair (or let the user choose). Use `image_search`/web search to actually *look at* the objects — real photos reveal properties memory misses.

## 2.2 Five forced connections
Force five conceptual links between A and B. Don't worry whether they're natural — the point is to make the mind find relationships it would never consider. (Lock + seashell: both protect something valuable; both are layered; distinctive exterior; inner/outer relationship; protection through form.)

## 2.3 Natural connections
Now study both objects properly and find similarities that genuinely exist:
colour relationships · shape & geometry · materials & texture · physical structure · behaviour & movement · construction mechanisms · pattern & repetition · symmetry/asymmetry · light & shadow · natural imperfections · symbolism · scientific/mechanical properties · emotional associations.

Forced connections make you think differently; natural connections make the identity coherent.

## 2.4 Translate into a design language
| Discovery | Website application |
|---|---|
| Layered structure | Layered compositions, z-depth, overlapping planes |
| Repeating geometry | Grid, pattern system, rhythm of sections |
| Protective shell | Framing devices, content containers, masks |
| Organic movement | Scroll and transition behaviour, easing character |
| Reflective surface | Material, light, shadow treatment |
| Interconnected structure | Navigation model, page relationships |
| Natural imperfection | Texture, grain, irregular edges, type quirks |

Select only the strongest 3–5 discoveries. Unused ones are not failures.

## 2.5 Central creative concept
Write one paragraph + a name for the concept. Then state how it drives each of: hero · typography · colour · layout · graphic elements · shapes · transitions · animation · navigation · backgrounds · interactions · page-to-page continuity.

**The objects are the foundation, not the illustrations.** The site should rarely show a literal clock or seashell; it should *behave and feel* like their union.

## Present
Show the concept as a visual board (artifact / HTML / Figma frame): the two objects (reference photos or sketches), the connections, a palette and type mood derived from them, 2–3 tiny composition sketches. Offer 2 alternative concepts in a line each so the user can redirect. Get approval.

Then run `references/creative-innovation.md` questions against the concept once: is there a more unexpected *but meaningful* angle?
